URI Office Unified · O2 design decision OD-U5

One Office workspace for sheets, documents, slides and PDFs

Two layouts for the same capabilities. Both keep the URI rail, the orb and the companion you already use in Office (AC19). Both show changes as cards you accept or reject, and both write nothing until you approve. Pick one; the O2 plan freezes on your choice.

Draft 2026-10-15 Branch phase/uri-office-unified-plan Static mockup: example content, not a running build
Direction B1

Three panes: files · page · companion

Recommended

Left: your files grouped by type, plus Templates and Workflows. Centre: the open file (sheet editor or page preview). Right: the URI companion, which holds plans, change cards, findings and approvals. A thin status line shows what is running and whether originals are untouched. Structure adapted from AFFiNE's sidebar + document + AI panel and Paperless-ngx's list + document detail.

Direction B2

Task panel · workbench · companion drawer

Left: a panel of tasks grouped by outcome (Create, Edit, Convert, Check, Combine) instead of by file type. Centre: a workbench that holds several open files at once. The companion moves to a drawer under the workbench. Structure adapted from Stirling-PDF's quick-access tool panel and workbench (frontend/editor/src/core/components/layout/Workbench.tsx, shared/quickAccessBar/).

Recommendation

B1. It keeps the companion where Excel users already find it, gives approvals full height, and adds one centre view per file type rather than a new layout. B2's task list can live inside B1 as the Templates and Workflows pages.

What is real today

Sheet view, change cards, approvals and the companion pane exist (M1/M2, not yet in canonical). LibreOffice page rendering was verified on this PC on 2026-10-15. Everything else on this page is the O2 to O8 plan.

Not included

Typing directly on a Word page. No free engine for that was found that runs inside URI. Mission Control and the Skill Command Center are separate milestones.
