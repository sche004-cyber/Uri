## 2. Frozen experiment design

1. Implement one offline producer that accepts an explicit `SourceSnapshot` containing the case's session context, a bounded list of authorized candidate IDs (C1/C2), and the corresponding source records from `candidate_library`. The harness constructs this snapshot without passing scorer-only keys. Reject duplicate/unknown IDs, missing record identity, inconsistent file IDs, or unapproved source types. There is no filesystem search, provider call, Graphify truth promotion, durable memory, or model call.
2. Emit a normalized, immutable evidence envelope with one canonical candidate set. Every entry keeps its original ID, source kind (`file_snapshot` or `synthetic_authorized_source`), record locator, authorization basis (`variant_available_candidates`), and available source metadata; missing provenance is explicit. Session attachment membership is retained only when the ID is in the authorized set. No candidate may be invented. The RAR projection maps this envelope to existing `RARCandidate`/`RARQuery`; metadata absent from the RAR contract remains in the envelope. A locator is an offline fixture locator, never a live provider token.
3. Do not promote fuzzy or model-derived evidence into a certainty anchor. `exact_id` is admitted only when the raw turn contains the complete candidate ID verbatim; `current_attachment_id` only when exactly one authorized turn attachment exists and the source ID matches. A unique verbatim title anchor may be admitted only when exactly one authorized record title appears intact in the raw text. Ambiguous or absent title/attachment state yields no such anchor. No `selected_ui_id` is synthesized because the corpus has no selected-UI field. Recency remains all-zero in the production-shaped primary comparison; any timestamp-rank sensitivity is reported separately and never called the primary result.
4. Replay D0 from the existing `build_turn_frame` path, D1R from its frozen detector, and D1RQ from its frozen detector. Each detector supplies only a span and local hint; it never supplies candidates, anchors, or binding authority. For each arm and C1/C2 source snapshot, invoke the unchanged `resolve_rar_deterministic_extended` on the producer projection. Report C3 (no authorized candidates) as a separate absence control. Attribution to human-marked spans is scorer-only and occurs after execution. An unmatched detector output is retained as an `UNATTRIBUTED_DETECTOR_FIND` row, never silently discarded. Its resolution is observed, but without an annotation its semantic correctness is `UNMEASURED`; see §5.
5. Compare a same-pool no-producer control (`RARCandidate` adapter with no anchors, as in the A2.8F production-shaped path) to the S4 producer for each arm. This isolates source-boundary effects from detector effects. The bounded context capsule is the envelope's candidate metadata and session attachment IDs; it does not include ground truth. Maximum: 16 candidate IDs and 16,384 UTF-8 bytes of canonical source-record JSON per snapshot. The frozen corpus maximum is 8 IDs and 1,972 record bytes. Preserve source order, count and byte count in telemetry; over-budget input must fail closed rather than silently truncate a relevant candidate. No semantic retrieval policy is claimed.

## 5. Scorer correction after first replay (2026-09-27)

The first implementation replay showed that the §2.4 phrase "false-positive row" was too strong for an unmatched detector span. For example, NB-A-02 annotates the filename as `r1` but the same turn says "it" about that file; NB-A-04 annotates the explicit file ID but also says "that's the scanned contract." An unmatched second phrase can be a valid reference, so the corpus supplies no ground truth for its binding. Calling its `RESOLVED` result a false binding would fabricate a safety finding. Preserve these rows with observed outcome and provenance; classify them as `UNATTRIBUTED_DETECTOR_FIND`, exclude them from correct/incorrect confident-binding numerators, and count them separately. A no-reference K case remains a genuine false-positive-control row. This is a scorer-only correction: no producer, detector, RAR, fixture, or frozen-anchor change. The first telemetry is superseded by the rerun after focused independent pre-audit of this amendment. A wrong confident binding on an *annotated* reference still stops any safety/promotion claim.
