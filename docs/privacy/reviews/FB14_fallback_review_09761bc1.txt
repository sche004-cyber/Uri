Findings

R1-01 MEDIUM RECALL (blocking:false) - dash runs and mixed punctuation between a credential label and its value
  still reach every destination raw; 6.15 row 1 says "any other punctuation run".
  `_OTHER_SEP` (classify.py:108) accepts 1-3 characters from [|>#*~^&%$@+<[]{}`'"\)] only, so a run that contains
  "-", "(", ",", ";", "/", ":", "=", "!", "?", "." or "_" mixed with others, or a run of dashes, matches no rule.
  pb2_realistic_seps (value Zq7wK2mP9x!, labels password / api key / DB_PASSWORD, 3 destinations): raw at WEB_SEARCH,
  EXTERNAL_AGENT and LOG for "my password -- X ok", " --> ", " - > ", " - - ", " -/ ", " /- ", "\u2014\u2014", ' :" ';
  for DB_PASSWORD also " :: ", ":- ", " :> ", " ->> ", ": - ", " // ". pb_label_sweep: 1206 of 4500 raw (2-character
  runs 167/517 per destination, 4-character 127/227). Fix: accept any run of 1-4 punctuation characters except the
  placeholder brackets (keep the value conditions), or state the residual.

R1-02 MEDIUM RECALL (blocking:false) - tables with ordinary header spellings send the credential column raw.
  `_CRED_HEADER.fullmatch` (classify.py:301-302, 353) accepts only single label words, and `_cells` (306-335) knows
  tab, "|" with outer pipes, "," and 2+ spaces. Raw at EXTERNAL_MODEL and LOG (pc_tables_cli): headers "Temp Password",
  "Login Password", "Wi-Fi password", "New password", "API Token", "Secret Key", "Access Key", "pwd."; a quoted CSV
  header ('"user","password"'); a ";"-separated CSV (European Excel export); a markdown table without outer pipes.
  None is among the 6.15 residuals. Fix: match a header cell that contains a label word (with a short qualifier), strip
  quotes, add ";" CSV and pipe tables without outer pipes; or state them.

R1-03 MEDIUM RECALL (blocking:false) - command-line credentials beyond the five listed tools pass raw.
  `_CLI_CRED` (classify.py:290-296) covers curl/wget/httpie -u, mysql/mariadb -p, sshpass -p, net use /user:, "login
  ... / X". Raw at EXTERNAL_MODEL and LOG: `docker login -u alice -p X`, `sqlcmd -U sa -P X`, `redis-cli -a X`,
  `mongosh -u alice -p X`, `7z x f.7z -pX`, `zip -P X`, `smbclient -U alice%X`, `xfreerdp /u:alice /p:X`,
  `net user alice X /add`, `htpasswd -b f alice X`, `ldapsearch -w X`, `ssh-keygen -N X`. 6.15 does not state them.
  Fix: a table of (tool, flag) pairs or a generic "-p/-P/--password/-a/-w/-N/ /p:" after a known tool; or state it.

R1-04 MEDIUM RECALL (blocking:false; precision, not a bypass) - the PC-23 rules refuse ordinary text.
  Hard refusals (CREDENTIAL) at WEB_SEARCH / EXTERNAL_*; LOG lines fully redacted. Examples refused by 09761bc1 and
  sent by 5e8a76d5: "API key + OAuth2.0 comparison", "password & OAuth2 vs SAML", "access token & refresh_token
  rotation", "Settings > Password > Change2FA", "secret key + HMAC-SHA256 python", "private key + RSA-4096 generate",
  "forgot password?Win11", "pass phrase | diceware_wordlist", "password ~ bcrypt12 rounds", "token | gpt-4o-mini price"
  (separator rule, classify.py:108, 174-178, 281); "sign in with Google / GitHub_SSO", "login with SSO / SAML2.0"
  (_CLI_CRED, 295-296); "name,city,pin\nRavi,Bengaluru,560034" and the TSV form (postal codes in a "pin" column - PC-19
  made "pin code 560034" postal), "| Model | Token | Price |" rows such as "8,192", "Secret    Value\nDB_HOST
  db-1.local", "token,pos\nrun3,VERB" (table rule, 301-370). Measured: 39/59 vs 8/59 (pa_benign_pc23); 175/800 (21.9 %)
  vs 55/800 (6.9 %) generated auth/dev queries (ph_benign_generated); Tavily capture: no request for "API key +
  OAuth2.0 comparison". FB13's benign sweep and PC-23's readability lists did not contain conjunction-style
  separators, so the effect is not recorded. Fix: treat "+", "&", "|", ">", "~", "*", "#", "@" as separators only when
  the value ends the clause (as the dash rule does) or holds mixed case + digit + symbol; exclude "pin" as a table
  header unless the cells are 3-8 digits next to a code word context (or treat a 6-digit "pin" column as ADDRESS);
  require the "login ... / X" value to differ from a word list of identity providers; or take an owner decision in
  the manner of LDEC-007.
