**Why the earlier repairs missed it:**

1. **Field labels:** build them only from visible text inside `<label>` and `aria-labelledby` targets, and send those label pieces through the same pixel check. 2. **Text over visible text:** in `onscreen.py`, drop any piece whose rectangles overlap another piece's by more than a small fraction, or at least the one the browser doesn't report on top at that point.
3. **Tests and docs:** add a self-contained Chromium test with the probe page that checks the whole request body. Update `docs/assist/03` and `A0_QUALIFICATION`, which currently imply all page text is pixel-checked.

If you'd rather accept the remaining overlap cases as part of L-A0-5, the report should say that explicitly. The label fix doesn't depend on that choice.
