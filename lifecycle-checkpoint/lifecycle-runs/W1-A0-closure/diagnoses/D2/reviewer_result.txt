**Why the repairs kept missing it:**
- **R1 (`16f75d8`) and R2 (`627f6b9`)** added the reviewer's example names or prefixes to the lists, one by one.
- **R3 (`1615512`)** added a `_STEMS` regex, but its contents were again the cited words. Stems like `apikey` or `*key` were never added. The short-code rule only fires on all-digit values. National-ID words still match only as whole words.
- **The R3 tests prove nothing new.** The generated test names are built from a stem list that mirrors the fix's own list. `key` appears only as a suffix there. Every name the fix doesn't know about is, by construction, absent from the tests. So "1,442 generated names pass" is not independent evidence.
- **The JS copy repeats the gap.** The parity test only proves the JS patterns are character-for-character the same as Python's, so any gap is copied into both layers.
- **The docs overclaim.** `A0_QUALIFICATION.md` says AC7 is MET on that circular evidence, for the third time.
