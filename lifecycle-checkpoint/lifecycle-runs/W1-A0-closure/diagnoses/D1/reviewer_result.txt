**Root cause:**
- `_words()` (`redact.py:44-46`) only splits on case changes, letter/digit changes and `_-.:/`. A lowercase run-together name stays one token: `"emailverificationcode"` stays as it is, and `"2facode"` becomes `"2 facode"`.
- Every multi-word or short rule in `_SENSITIVE_WORDS` (`redact.py:25-30`) is wrapped in `\b`: `\b(...|mfa|2 ?fa|secret|token|auth|...)\b`, `\bone ?time\b`, `\btwo ?factor\b`, `\bverification ?code\b`. Those rules can only match a word on its own, which a run-together name never produces.
- The fallback `_RUN_TOGETHER` (`redact.py:35-41`, copied to `snapshot.js:12`) is a list of prefix+stem combinations. Names outside the list miss: `smspin` (no `sms` before `pin`), `mfacode`, `onetimecode`, `cardcode`, `cardverificationcode` (no matching prefix before `code`), and token/secret anywhere.
- The short-digit fallback `_CODE_LABEL = \bcode\b` (`redact.py:61`, `snapshot.js:14`) needs `code` as its own word, so `...code` names miss it.
- The JS checks at `snapshot.js:73,76-77` use the same logic, so both layers fail in the same way.

**Why the earlier repairs missed it:**
- **Repair 1 (`16f75d8`):** it improved the case and digit splitting in `_words` and added `[a-z]*otp`, `mpin`, `tpin`, `ccv` and `acct`. It still assumed a name can be split into words, which is false for all-lowercase run-together names.
- **Repair 2 (`627f6b9`):** it added `_RUN_TOGETHER` as a list of prefixes for exactly the 20 names the reviewer gave. The comment at `redact.py:31-34` says so: "pin / pass / code only after a known prefix".

**Proposed fix:** I tested this as a Python prototype in `/tmp/diagD1/proto.py`; it is not in the repo, and the JS side has not been run.
- Match sensitive stems anywhere in the joined name: otp (not followed by a/h/l/o, so hotpot, footpath and hotplate stay readable), mfa, 2fa, tfa, onetime, twofactor, verif(ication), authenticat, cvv, cvc, ccv, token, secret, password, passwd, passcode, pwd.

- With the prototype, all 16 leaking names (values `482913` and `123`) are caught, and none of the 22 readable names (hotpot, footpath, spinner, pincode, zipcode, countrycode, promocode, author, account and others) is flagged.
