I've repaired R2-01. Lowercase run-together names like `otpcode`, `cardcvv`, `newpassword`, `upipin`, `loginpwd`, `userpass` and `verifycode` are now treated as sensitive. This works both in Python (`uri_assist/redact.py`) and in the in-page script (`uri_assist/browser_extension/snapshot.js`). Nothing is committed.

**The fix:** both layers now run one shared extra check on each word of a field's name, id, label, placeholder or aria-label (`_RUN_TOGETHER` / `RUN_TOGETHER`):
- **Long stems match anywhere in a word:** `password`, `passwd`, `passcode`, `passphrase`, `pwd`, `cvv`, `cvc`, `ccv`.
- **`otp`** matches only at the start or end of a word, or before a known ending (`code`, `value`, `number`, `pin`, …). So `footpath`, `hotpot` and `hotplate` stay readable.
- **`pin`, `pass` and `code`** match only after a known prefix (e.g. `upi`/`atm`/`card`/`security` + `pin`; `user`/`login`/`new` + `pass`; `verify`/`sms` + `code`). So `pincode`, `zipcode`, `spinner`, `camping`, `passenger`, `compass` and `bypass` stay readable.
