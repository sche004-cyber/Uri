**R1-01 — numbers after a letter or dot were ignored** (`uri_web/evaluate.py:15`)
- Number matching was blocked whenever the number followed a letter or a dot. Now only a preceding digit blocks it, so `Rs.500`, `approx.900`, `No.5` and `Rs.1,250.50` all yield their numbers.
- As a result, a sentence citing `Rs.900` against a source that says `Rs.500` is dropped as `NUMBER_NOT_IN_CITED_SOURCE`, and two pages saying `Rs.500` and `Rs.900` are reported as a conflict. A correctly cited `Rs.500` is still kept.
- Tests: `tests/web/test_w1_r1_review_regressions.py`.

**R1-02 — OTP, card-check and PIN field names were missed** (`uri_assist/redact.py` and `uri_assist/browser_extension/snapshot.js`, same change in both)
- Field names are now also split at an acronym followed by a word (`OTPCode` → `otp code`) and between letters and digits (`cvv2` → `cvv 2`).
- New names covered: any word ending in `otp` (so `SMSOTP`), `2 fa`, `mpin`, `tpin`, `ccv`, `acct number/num/no`, and `card expiry/exp/expiration`.
- I extended `tricky_fields.html` with 12 such fields. The existing in-page vs Python parity test now covers them, and a new real-Chromium test checks that none of their values leave the page.
- Names that should stay readable still do: `pincode`, `spinner`, `hotpot`, `address2`, `zip5`, `cardholderName` and `account`.
- Tests: `tests/assist/test_a0_r1_review_regressions.py`.

**R1-03 — Ask stayed disabled after Stop and a new share** (`uri_ui/lib/living/assist/assist_controller.dart`)
- `revoke()` now clears the running question as well as the answer. `grant()` clears both too, because the worker discards answers that belong to an earlier grant.
- I added two tests to `uri_ui/test/living/assist_mode_test.dart`: a controller test, and a widget test that asks, gets an answer, stops, shares again, then checks that Ask is enabled and no "reading" message shows.

**R1-04 — the in-page snapshot didn't mask several texts** (`snapshot.js`)
- The masking already applied to page text now also covers the title, headings, field labels, placeholders, field ids and names, and the whole URL. Already-masked `key=` values in the URL are not counted twice.
- `run_snapshot.cjs` takes an optional `SNAPSHOT_URL` so the URL can be tested. The page is served locally, with no network.
