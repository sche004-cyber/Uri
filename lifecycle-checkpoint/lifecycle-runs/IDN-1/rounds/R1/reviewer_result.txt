**R1-01 (MEDIUM, blocking): the KELVIN SIGN gets past the non-English check.**
- `check_url` decides whether a host is non-ASCII only after `urlsplit().hostname` has lower-cased it (`uri_web/netpolicy.py:111` and `:131`). U+212A KELVIN SIGN lower-cases to ASCII `k`. It is the only character in Unicode that does.
- So `http://\u212aelvin.com/` is accepted as `kelvin.com` and the host is contacted. This happens for a user URL, a search hit and a redirect: the request reaches `kelvin.com`, the job completes, the count is 0 and no note appears.
- The real-world risk is low, because the host contacted and the label shown are both the genuine `kelvin.com`. But it breaks the plan's rule that "any character outside ASCII" is refused, and the review focus lists this kind of bypass as blocking.
- Fix: test `parts.netloc.isascii()` on the raw URL text, and add the case to the tests.

**R1-02 (MEDIUM, blocking): one blocked site is counted more than once, so the note says "Blocked 2 sites" when there was one.**
The count adds one per search hit and one per refused fetch, with nothing removing repeats of the same site (`uri_web/search.py:117-123`, `uri_web/pipeline.py:152` and `:179`). Each of these gives a count of 2 for a single site:
- Two search results from the same site (`bücher.de/1` and `bücher.de/2`). This is very likely with real searches.
- The first provider returns only blocked hits, so it reports no results and the next provider returns the same hit.
- The same site given as a user URL and also returned as a search hit.
- Two different pages that both redirect to the same blocked site.

Fix: collect the refused host names in a set across the whole job and report how many are in it.

**R1-03 (LOW, not blocking): a percent-encoded address gets no explanation.**
A redirect to `http://%D1%80aypal.com/` (a browser would read this as a Cyrillic look-alike of paypal.com) is refused with `HOST_INVALID`. It is never contacted, but it isn't counted and the user gets no note. Either decode percent signs in the host before the non-ASCII check, or accept and document this.
