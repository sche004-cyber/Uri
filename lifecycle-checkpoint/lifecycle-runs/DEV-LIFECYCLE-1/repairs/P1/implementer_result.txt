**What changed** (all in `scripts/dev_workflow/lifecycle.py` unless noted):

- **R2-01 (forged round + edited `resume_to`):**
  - `verify()` now requires round and repair numbers to be exactly 1..n in order, with no duplicates.
  - Each recorded entry in `state.json` must equal its hashed `round.json` / `repair.json`.
  - A round with no review event must be a genuine started review, and the only repair allowed without an event is the last one, still in progress.
  - `resume_to` and `blocker` are now written into the BLOCKED / WAITING_FOR_MODEL stage events and checked against `state.json`.
  - `accepted_review()` now reads the independent ACCEPT only from intact `REVIEW_RECORDED` events and hash-checked `round.json` files, never from `state.json`.
- **R2-02 (replace refs hiding a protected change):**
  - Every driver git call now runs with `--no-replace-objects` and `GIT_NO_REPLACE_OBJECTS=1`. That covers `worktree_changes`, merge-base, merge and push, which previously called git directly.
  - `refs_digest` now includes every `refs/replace/*` ref, so creating one during a review or repair is caught as tampering.
  - `git_control_digest` now also covers the files in the shared git dir's `info/` folder (grafts, attributes, exclude).
  - `changed_paths` now uses `--no-renames`, so a rename out of a protected path also lists the protected source.
  - `git replace` is added to the denied commands in `lifecycle_providers.py`. That list is a convenience, not the real boundary.
- **R2-03 (rewritten `.git` gitfile):** a new `worktree_identity()` check confirms the worktree's `.git` still leads to its own git dir. It runs before and after the implementer, in both review snapshots, at the start of each `run()` step, and inside `_restore()`. If it fails, the run blocks as TAMPER and nothing is reset.
- **R2-04 (repair deleting a test file):**
  - A repair that deletes an existing test file is refused (`DELETES_TESTS`).
  - Regression proof only uses test files that exist in the repair commit.
  - Everything after the driver's commit moved into `_commit_and_prove()`, wrapped so that any error records the repair as REFUSED and restores the worktree to the pre-repair commit.
- **R2-05 (GPU lease busy):** for a GPU gate, exit 75 together with gpu_lease's `"refused"` report now gives status BLOCKED, so the run stops as BLOCKED (RESOURCE) instead of creating gate findings.
