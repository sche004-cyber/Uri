## 3. Raw error vs URI containment (select cases, all repeats)

From `INTERIM_2_HOLDOUT.md` §3: of Needle P1's proposals, 86 were stopped by URI containment and 75 executed incorrectly; for Granite JSON P1, the figures were 113 and 68. Containment catches unoffered tools, multiple calls, missing or non-verbatim arguments and bad enums. It does not catch a wrong tool that receives a real span ("transcript for 20BT302" → `read_attached_file("20BT302")`), a wrong span from the request or context, or a substring that is itself a valid span. Fault test `corrupted_filename_copy` (`grant_report_q2.pd`, a prefix of the real name) passed the verbatim check and executed. **No model received credit for a value URI supplied or corrected**: under the typed catalogue URI fills the argument only from the model's own verbatim span; under R1 the model gets credit for the action choice only.

Needle's per-case p50 (about 720 ms) is dominated by building a new agent whenever the offered tool set changes. With a fixed tool set its warm inference is 142–156 ms, the same as Granite on GPU. On equal (CPU) placement, Granite JSON and Needle have the same holdout p50 (745 vs 734 ms).

Resource exhaustion test (78,022-character document, `faults.py`): Needle returned no output after 7.6 s. Granite returned the right value in 399 ms because Ollama truncated the prompt to 2,050 tokens and the value sat in the retained tail. Neither failure was announced as truncation, so a value that falls outside the retained window would silently go missing.

## 6. Conclusion for this report

On this workload, neither specialist is reliable enough for any task class to be handled locally without a stronger check. Against the best Granite variant per family, needle_P1 is behind on 6 families (EXTRACT, NEGATION, REFERENCE, ROUTE, SELECT, SEMANTIC). It ties on 3 (ARGS, INJECTION, MULTISTEP) and is ahead on 3 (AMBIGUITY 2 vs 1, ESCALATE 5 vs 4, UNSUPPORTED 4 vs 2 of 10). Needle's edge is confined to abstention families, where it is still wrong on most cases.
